<h2>✨ Features</h2>

<ul>
  <li><b>Advanced Scientific Logic:</b> Complete support for trigonometric (<code>sin</code>, <code>cos</code>, <code>tan</code>), inverse trig (<code>asin</code>, <code>acos</code>, <code>atan</code>), hyperbolic (<code>sinh</code>, <code>cosh</code>, <code>tanh</code>), factorials, roots, and mathematical constants (&pi;, <i>e</i>).</li>
  <li><b>Calculation History:</b> Built-in history log to track, review, and reuse previous calculations seamlessly.</li>
  <li><b>Degree / Radian Dynamic Switch:</b> Seamless angle evaluation and result conversions between <code>Deg</code> and <code>Rad</code> modes.</li>
  <li><b>Real-Time Live Calculation:</b> Instant formula parsing with automatic open/close parenthesis balancing.</li>
  <li><b>Interactive Function Toggle:</b> Smooth mode transitions to switch between base operations and advanced scientific inputs (<i>x³</i>, <i>x!</i>, inverse keys).</li>
  <li><b>Modern & Responsive UI:</b> Engineered using Tailwind CSS grid layouts with dynamic transition effects and dark-theme aesthetic.</li>
</ul>

<h2>⚙️ Local Setup & Installation</h2>

<ol>
  <li>
    <b>Clone the repository:</b>
    <pre><code>git clone https://github.com/AaserEslam/React-Smart-Scientific-Calculator.git</code></pre>
  </li>
  <li>
    <b>Navigate to project directory:</b>
    <pre><code>cd React-Smart-Scientific-Calculator</code></pre>
  </li>
  <li>
    <b>Install dependencies:</b>
    <pre><code>npm install</code></pre>
  </li>
  <li>
    <b>Start the development server:</b>
    <pre><code>npm run dev</code></pre>
  </li>
</ol>
